# OpenClaw AI Agents Guidebook

A practical handbook for designing, building, testing, and deploying AI agents and chatbots in OpenClaw.

## Files

- `index.html` - landing page
- `guidebook.html` - full guidebook
- `vercel.json` - simple static routing config for Vercel

## Deploy

1. Create a new GitHub repo named `openclaw-ai-agents-guidebook`
2. Upload these files through the GitHub web UI
3. Import the repo into Vercel
4. Deploy as a static site
